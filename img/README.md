# Images

Put the site's images here. On deploy they are copied into `public/img/`
and served from `https://davey.mywindowwashing.com/img/<filename>`.

Upload straight into this folder — on GitHub, open it and use
**Add file → Upload files**. Filenames must match what `public/index.html`
references, exactly, including the extension and lower case.

This README is not published.
